# React Native Calorie Tracker

A cross-platform mobile nutrition and fitness tracker built with React Native and Expo as part of the SoftUni mobile development curriculum.

## Features

- **Daily Caloric Balance:** Monitor daily calorie targets, calories burned, and remaining calorie allowance at a glance.
- **Meal Logging:** Modal dialog for quickly logging meals with title, category, and calorie values.
- **Structured Meal Breakdown:** Categorized view (Breakfast, Lunch, Dinner, Snacks) for nutritional tracking throughout the day.
- **Modern UI:** Styled with `lucide-react-native` icons and safe-area layout support for iOS and Android.

## Tech Stack

- **Framework:** [Expo](https://expo.dev/) (SDK 54) / [React Native](https://reactnative.dev/)
- **Icons:** `lucide-react-native`
- **Language:** JavaScript (ES6+ / JSX)

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (LTS version recommended)
- [Expo Go](https://expo.dev/go) installed on your mobile device (iOS / Android), or an emulator.

### Installation & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/niksata-ivanovw/softuni-react-native-calorie-tracker.git
   cd softuni-react-native-calorie-tracker
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npx expo start
   ```
4. Scan the QR code using the **Expo Go** app on Android or the default Camera app on iOS.\n
